# Flow.io Cards 0.3.4

**Statut : version annulée en tant que publication distincte.** Les corrections prévues pour 0.3.4 restent incluses dans la branche `feature/maintenance-menu` et seront livrées avec la version 0.3.5.

Ces notes ne signifient pas que le bundle a été construit, que les tests sont passés, qu’un brouillon GitHub a été créé ou que la version a été publiée.

## Corrections reportées en 0.3.5

- Sur les écrans de moins de 700 px, le bouton interactif « Système » reste dans le shadow DOM du composant Flow.io plutôt que dans celui de la carte d’en-tête native Home Assistant.
- Un emplacement non interactif de 44 px est réservé après le titre natif. Le bouton Flow.io se superpose à cet emplacement pour conserver « titre + Système à gauche, badges Traitement et Alertes à droite ».
- Le positionnement est recalculé au redimensionnement du composant ou du titre et lors des transitions entre mobile et desktop. Les observateurs et l’emplacement réservé sont nettoyés lors de la déconnexion du composant.
- Sur desktop, le bouton injecté après le titre natif est conservé. Si le titre natif est introuvable, le bouton externe reste disponible.

## Tests et validation

Les scénarios Playwright couvrent les taps d’ouverture et de fermeture, les transitions mobile → desktop → mobile et le bouton de secours lorsque le titre natif est introuvable. Les assertions de `e2e/header-badges.spec.ts` imposant le placement près du titre et l’alignement des badges restent inchangées.

La première modification a révélé une régression de placement à 390 px. Le correctif de positionnement a été commité, mais sa réussite en CI et sur une instance Home Assistant réelle doit encore être confirmée avant la release 0.3.5. Aucun résultat de test ni contrôle matériel n’est certifié par ces notes.

## Installation et migration

Aucune nouvelle option de configuration n’est introduite par ces corrections. Voir `README.md` et `docs/HACS.md` pour l’installation. Ne charger qu’une seule copie du bundle JavaScript et recharger le frontend après la mise à jour.

## Publication

La version 0.3.4 ne doit pas faire l’objet d’un tag, d’un brouillon GitHub ou d’une publication distincte. Utiliser la préparation et la publication de la version 0.3.5, décrites dans [`docs/releases/v0.3.5.md`](v0.3.5.md).

Les protections, interlocks, limites de dosage et arbitrages restent dans Flow.io. Cette version ne certifie ni l’installation physique ni la sécurité chimique.
